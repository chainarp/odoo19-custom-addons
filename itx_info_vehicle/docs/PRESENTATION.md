# ระบบราคาตามสภาพ

## แหล่งที่มา (Origin)

| ประเภท | คำอธิบาย | ราคา |
|--------|----------|------|
| **OEM** | อะไหล่แท้จากโรงงาน | สูงสุด |
| **Aftermarket** | อะไหล่เทียบ/เทียม | ต่ำกว่า |
| **Reconditioned** | รีบิ้วท์/ซ่อมใหม่ | ปานกลาง |

## สภาพ (Condition)

| สภาพ | คำอธิบาย | % ราคา |
|------|----------|--------|
| **New** | มือหนึ่ง ยังไม่แกะกล่อง | 100% |
| **Like New** | มือสอง สภาพใหม่มาก | 70-80% |
| **Good** | ใช้งานได้ดี มีรอยบ้าง | 50-60% |
| **Fair** | ต้องซ่อม/ปรับแต่ง | 30-40% |

# Unique Key: ไม่มีอะไหล่ซ้ำ

## อะไหล่ต่างกันได้ 6 วิธี

```
┌────────────────────────────────────────────────────────┐
│                    UNIQUE KEY                          │
├────────────────────────────────────────────────────────┤
│  1. variant_id        รุ่นรถต่างกัน                     │
│  2. part_category_id  หมวดอะไหล่ต่างกัน                 │
│  3. name              ชื่อต่างกัน (ซ้าย/ขวา)            │
│  4. part_origin       แหล่งที่มาต่างกัน (แท้/เทียม)      │
│  5. condition         สภาพต่างกัน                      │
│  6. oem_part_number   เลข OEM ต่างกัน (ถ้ามี)          │
└────────────────────────────────────────────────────────┘
```

### ตัวอย่าง: ไฟหน้า Vigo 3.0G

| Name | Origin | Condition | OEM Part No | = Record |
|------|--------|-----------|-------------|----------|
| ไฟหน้า**ซ้าย** | OEM | Like New | 81170-0K440 | Record 1 |
| ไฟหน้า**ขวา** | OEM | Like New | 81130-0K440 | Record 2 |

**name ต่างกัน = คนละ record**

# ข้อดีของระบบ

## 1. ค้นหาง่าย

```
พิมพ์: "VIG G2 ไฟหน้า"
ผลลัพธ์: แสดงเฉพาะไฟหน้า Vigo Gen 2 ทั้งหมด
```

## 2. Filter ตามต้องการ

- กรองตามยี่ห้อ
- กรองตามรุ่น
- กรองตาม OEM/Aftermarket
- กรองตามสภาพ

## 3. รหัสมีความหมาย

```
TOY-VIG-G2-3GDC-FHL-00001
          ↓
เห็นปุ๊บ รู้เลยว่า:
"ไฟหน้า Toyota Vigo Gen 2 Champ 3.0G Double Cab"
```

## 4. ขยายได้ในอนาคต

- เพิ่มยี่ห้อใหม่
- เพิ่มรุ่นใหม่
- เพิ่มหมวดอะไหล่ใหม่

# Q&A

## คำถามที่พบบ่อย

**Q: ถ้าอะไหล่ใช้ได้หลายรุ่น ทำอย่างไร?**
A: สร้างหลาย record (1 record ต่อ 1 variant ที่รองรับ)

**Q: ถ้าไม่รู้ OEM Part Number?**
A: เว้นว่างไว้ก่อน กรอกทีหลังได้

**Q: ถ้าเพิ่มยี่ห้อใหม่?**
A: เพิ่มได้เลยในหน้า Vehicle Brands

**Q: ถ้าสภาพเปลี่ยน (Good → Fair)?**
A: สร้าง record ใหม่ (เพราะสภาพต่าง = ราคาต่าง = คนละ record)
